Paramètres difficulté

Facile : Une chauve-souris, peu de couloirs.

Moyen : 2 chauve-souris, plus de couloirs.

Difficile : 2 chauve-souris, beaucoup de couloirs.

Mode de jeu

Mode Express : Le nombre de salle est réduit. Intensitée beaucoup plus élevée, mais attention les dangers sont plus proches !

Mode Aveugle : Vous ne voyez que votre case dans le labyrinthe... Fiez vous aux indices donnés !

Attention : les deux modes peuvent être séléctionné en même temps.
